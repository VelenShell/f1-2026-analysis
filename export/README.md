# Словник даних

Усе вивантажено з PostgreSQL-бази проєкту, джерело — [OpenF1 API](https://openf1.org).
Перевірено звіркою з незалежним джерелом (Jolpica/Ergast): особистий залік
2026 збігається до очка.

Кодування UTF-8, роздільник — кома, десятковий роздільник — крапка,
час у UTC (ISO 8601).

## Плоскі таблиці

### `f1_2026_race_analysis.csv` — 721 рядок

Один рядок = **один пілот в одній гонці**. Сезони 2025 і 2026, тестові заїзди
виключені. Основна таблиця для перегляду й більшості зрізів.

| стовпець | опис |
|---|---|
| `year`, `round` | сезон і порядковий номер етапу |
| `meeting_name`, `circuit` | назва Гран-прі та коротка назва траси |
| `is_street` | вулична траса (там сходи переважно від контакту зі стіною) |
| `driver`, `driver_code`, `team`, `driver_number` | пілот, код, команда, номер боліда |
| `quali_position` | позиція в кваліфікації цього ж етапу |
| `finish_position`, `points` | фініш і нараховані очки |
| `dnf`, `dsq` | зійшов / дискваліфікований |
| `number_of_laps`, `total_laps` | кіл за протоколом і кіл із виміряним часом |
| `clean_laps` | скільки кіл придатні для вимірювання темпу (див. нижче) |
| `median_clean_lap_s` | **медіанний час чистого кола** — основний показник темпу |
| `best_lap_s` | найкраще чисте коло |
| `gap_to_leader_s`, `laps_down` | відставання в секундах або в колах |
| `pit_stops`, `compounds_used` | кількість заїздів і використані компаунди |
| `overtakes_made` | обгонів здійснено |
| `track_temp_avg/max`, `air_temp_avg`, `humidity_avg`, `rainfall_max` | погода за сесію |

### `f1_2026_dnf_weather.csv` — 235 рядків

Зріз під перевірку гіпотези «спека підвищує кількість сходів». Одиниця
спостереження — **пілот × гонка**, лише 2026, без тих, хто не стартував.

Чому саме такий грануляр: на рівні гонок вибірка складає 11 точок, на цьому
рівні — 235. Статистику на 11 спостереженнях будувати немає сенсу.

## Зіркова схема (`star/`) — для Power BI

Зв'язки будуються по числових ключах.

```
dim_driver ─┐
dim_team ───┼─→ fact_entry ─┐
            │               ├─→ fact_result
dim_circuit─┴─→ dim_meeting─┴─→ dim_session ─┬─→ fact_lap
                                             ├─→ fact_stint
                                             ├─→ fact_pit
                                             ├─→ fact_weather
                                             ├─→ fact_overtake
                                             ├─→ fact_position
                                             └─→ fact_race_control
```

| файл | рядків | що це |
|---|---|---|
| `dim_driver` | 40 | пілоти. **Ключ — людина, не номер боліда** |
| `dim_team` | 12 | команди з фірмовим кольором (hex без решітки) |
| `dim_circuit` | 26 | траси, з ознакою вуличної |
| `dim_meeting` | 52 | етапи, з порядковим номером і ознакою тестів |
| `dim_session` | 254 | сесії, з ознаками скасування та нарахування очок |
| `fact_entry` | 3 796 | склад учасників: хто під яким номером за яку команду |
| `fact_result` | 3 782 | результати всіх сесій |
| `fact_lap` | 110 430 | кола, вже збагачені командою, компаундом і віком гуми |
| `fact_stint` | 16 024 | відрізки на одному комплекті гуми |
| `fact_pit` | 15 068 | заїзди в бокси |
| `fact_weather` | 22 080 | погода, вимір раз на хвилину |
| `fact_race_control` | 11 738 | прапори, сейфті-кари, повідомлення дирекції |
| `fact_overtake` | 9 498 | обгони |
| `fact_position` | 133 107 | позиції в часі |

## Важливо знати про ці дані

**Номер боліда не є ідентичністю пілота.** У 2025 під №1 їздив Ферстаппен,
у 2026 під №1 їздить Норріс — номер переходить до чемпіона. Тому ключем
у `dim_driver` є людина, а `driver_number` живе у `fact_entry` як атрибут
участі в конкретній сесії. З'єднання по номеру злило б різних пілотів.

**Що таке «чисте коло» (`is_clean_lap` у `fact_lap`).** Коло придатне для
вимірювання темпу, якщо: час кола виміряно, це не виїзд із боксів, не коло
заїзду в бокси і воно не перетинається з періодом сейфті-кара, віртуального
сейфті-кара чи жовтого прапора. Складові винесені окремими стовпцями
(`under_sc`, `under_yellow`, `is_pit_in_lap`), тож означення можна
перевизначити.

Це не косметика. Медіана по всіх колах ставить Расселла й Антонеллі на
85.217 і 85.213 — різниця 0.004 с, тобто нуль. По чистих колах — 83.510
і 83.396. Сире значення часу кола маскує різницю між пілотами майже повністю.

**Дві скасовані гонки.** Бахрейн і Саудівська Аравія (квітень 2026)
скасовані й у даних відсутні; Бахрейн перенесено на жовтень. У 2026 проведено
**11 гонок із 23**.

**Перемоги: гонки і спринти рахуються окремо.** Якщо рахувати
`finish_position = 1` по всіх залікових сесіях, у Антонеллі вийде 7 замість
6 — бо додасться спринт.

**DRS у 2026 немає.** Відповідне поле телеметрії порожнє на 100% — новий
регламент замінив DRS режимом наддачі потужності.

**Телеметрії тут немає.** Сирі дані — 74 млн рядків (близько 5 ГБ), у
репозиторій не поміщаються. Відтворюються запуском `ingest/fetch_openf1.py`.
Похідні від них показники будуть окремими файлами.
